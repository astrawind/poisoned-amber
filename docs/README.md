# Запуск Poisoned Amber

## Офлайн-проверка

Нужны Go 1.24.0 и C-компилятор (SQLite-драйвер использует CGO).

```sh
go test ./...
go test -race ./...
go vet ./...
go build ./cmd/bot ./cmd/content
go run ./cmd/content -file content/test.json
go run ./cmd/content -file content/test.json -db amber.db
```

`TestOfflineLobbyCombatRecoveryAndDuplicate` проходит лобби двух пользователей, бой, конкурентные повторы, повторное открытие SQLite, таймеры и доставку fake-адаптером. Доменные тесты отдельно проходят маршрут и исходы. Они не доказывают баланс и длительность партии.

## Живой запуск

1. Создайте бота через официальный @BotFather, получите токен.
2. Скопируйте `.env.example` в `.env`, заполните `BOT_TOKEN`. Не отправляйте токен в чат разработки. Ограничьте доступ: `chmod 600 .env`.
3. Запустите:

```sh
docker compose up --build -d
docker compose logs -f bot
```

4. Каждый участник открывает личный чат с ботом, отправляет `/start`, затем `/adult`.
5. Глава: `/create вашПароль`. Остальные: `/join КОД вашПароль`. Кнопками выбрать класс, предысторию и готовность; глава начинает поход.
6. В бою доступны действия из текущей памяти, выбор цели и пропуск. `/sync` обновляет карточку. `/help` возвращает актуальное состояние.
7. При наградах кнопками убирайте и добавляйте варианты; карточка показывает выбранный набор и будущие характеристики. Нажмите «Подтвердить выбор». Точный порядок: `/memory ID1 ID2`, затем `/confirm`; пустая память: `/memory empty`, `/confirm`. После таймаута остаётся прежняя память.
8. На испытании следуйте персональной карточке. Анаграмма: `/answer слово`. Голосование и роли проверяются сервером.
9. Глава может использовать `/pause` между встречами и `/resume`. `/leave`, затем `/leave_confirm` отключает участие и рассылку. `/return КОД` возвращает существующего участника, если у него нет другой комнаты.

Проверка вживую: два разных аккаунта, затем 3–7; одинаковые классы; повторное нажатие; старые кнопки после смены фазы; таймаут; блокировка бота одним участником; перезапуск контейнера в бою и наградах; приватность секретов; полный маршрут и финальное голосование. Проверьте удобство карточек на телефоне и фактическую длительность. Не запускайте второй экземпляр polling с тем же токеном.

Без Docker: экспортируйте `BOT_TOKEN` безопасным способом в окружение и выполните `go run ./cmd/bot`. `.env` автоматически читает только Docker Compose.

## Контент и миграции

При старте схема SQLite создаётся автоматически (версия 1), пакет валидируется и импортируется целиком. Версия пакета неизменяема: изменение содержимого требует нового `Version`. Активная комната продолжает использовать закреплённую версию из БД. Импорт через контейнер:

```sh
docker compose run --rm --entrypoint /app/bin/content bot -file /app/content/test.json -db /data/amber.db
```

Для изменённого пакета замените `content/test.json`, задайте новый `Version`, проверьте `cmd/content`, пересоберите образ. Новый набор используется новыми комнатами. Новые слова и варианты существующих эффектов добавляются JSON. Новые механики требуют Go-кода. Отдельного UI импорта нет.

## Резервная копия

Не копируйте только db-файл при работающем сервисе. Простой безопасный вариант — остановить сервис и скопировать весь том, включая WAL/SHM, затем запустить. Узнайте имя тома через `docker volume ls`; Compose добавляет имя проекта перед `amber-data`. Пример с Docker volume:

```sh
docker compose stop
mkdir -p backup
docker run --rm -v poisoned-amber_amber-data:/data:ro -v "$PWD/backup:/backup" debian:bookworm-slim tar czf /backup/amber.tar.gz -C /data .
docker compose start
```

Восстановление: остановите сервис, сохраните текущий том отдельно, восстановите архив в пустой том с тем же владельцем UID 10001, затем запустите. Не смешивайте файлы разных копий. Архив содержит секреты испытаний и хеши паролей; храните его с ограниченным доступом.

## Эксплуатационные ограничения

Одна пишущая реплика; SQLite на локальном диске. Отправка выполняется одним worker с сохранением порядка на чат; 429 откладывает адресата. Неоднозначный сетевой сбой может дать повтор сообщения, игровой эффект защищён транзакцией и дедупликацией. База хранит историю обработанных команд и исходящих кнопок; автоматическая очистка пока не реализована. Баланс, удобство и целевые 30–45 минут требуют живого плейтеста.

Проверка HTTP-адаптера не открывает сетевой порт: тестовый RoundTripper воспроизводит ответы Telegram 429 и ошибку редактирования. Docker-образ собран и его команда контента проверена; реальный Telegram должен быть проверен после создания бота. На macOS `go test -race` может завершиться успешно с предупреждением системного linker о `LC_DYSYMTAB`.
